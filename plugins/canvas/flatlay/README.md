# 批量平铺节点

在现有自由画布上逐图生成单件服装的正面或背面白底立体平铺图，可选腾讯云数据万象去底。预设沿用用户已验证的提示词，仅增加 `{目标单品}` 变量。

## 本地试用

工作目录为 `/Users/lianglei/Projects/git/new-infinite-canvas.codex-worktrees/flatlay-canvas`。Web 依赖已安装；按照项目约定，本轮没有执行构建。下面命令供本地试用时执行：

```sh
npm --prefix plugins/canvas/sdk install --ignore-scripts
npm --prefix plugins/canvas/flatlay install --ignore-scripts
npm --prefix plugins/canvas/flatlay run build
npm --prefix web run dev
```

插件构建会同步 `web/public/plugins/flatlay.js` 并更新本地插件清单。打开此工作树的 Vite 地址，在「节点管理」的本地插件中启用「批量平铺」，再添加节点。不要打开仍在运行的其他工作树服务来验收本次改动。若需重新安装 Web 依赖，仓库现有 antd peer 冲突需使用 `npm --prefix web install --legacy-peer-deps --ignore-scripts`。

1. 将图片或图片组连接到批量节点，在「图片」页点击「读取上游」或「更新上游」。每条输入独立处理，不会将多张衣服合成一次请求。
2. 填写每张的目标单品，或用统一目标应用全部；留空时由所选看图模型识别。选择生图模型，尺寸留空沿用画布配置。
3. 在「设置」页展开预设可查看或编辑提示词，保留 `{目标单品}`。默认只生成白底；需要透明图时勾选「附加透明 PNG」并配置腾讯。
4. 点击底部「生成 N 张」。每次只处理一张，失败继续下一张，不自动重试。白底与透明底会作为普通图片节点排列并连线。
5. 去底失败后可复用已保存白底重试；记录页的「重新生成」会创建新结果，保留旧图。点击「选择结果」后使用画布已有导出工具栏。

## 腾讯配置

支持商品抠图 GoodsMatting 和通用抠图 AIPicMatting，不自动切换或回退。输入 SecretId、SecretKey、带 APPID 后缀的 Bucket、地域及可选临时 Token；也可导入 MindFrame 的 JSON（小写 `secretId`、`secretKey`、`bucket`、`region`，可选 `appId`）。

配置只留当前页面内存，刷新需重新输入或导入；不随画布或应用配置导出。浏览器直接签名和访问 COS，没有凭据托管后端。桶必须开通对应数据万象能力，并允许当前站点的 CORS PUT、GET、DELETE，以及 Authorization、Content-Type、可选 x-cos-security-token 请求头。代码不自动修改云权限。

处理的是生成后的白底单品图：上传临时 COS 对象→抠图→校验真实 alpha→保存本地→尝试清理临时对象。清理失败会显示对象路径，需到 COS 核实。生图及腾讯服务可能计费；停止不能撤销已受理请求的费用。上传在途时等待返回再清理，不新增超时或自动重试。

## 文件夹批量与正背切换

在节点管理中添加「文件夹图片」，点击「选择文件夹」。图片会按相对路径排序并保存本地，包含子目录、忽略非图片；重复选择未改动文件不会重复添加。文件夹节点连到「批量平铺」后，点击「更新上游」即可读取每张图，不需要分别连线。原有单图、图片组输入仍可混用。导入后不会监听磁盘文件夹变动；新增文件需再次选择文件夹，再更新上游。

「图片」页选择正面平铺或背面平铺，设置页可分别编辑两套预设。一次批次使用一个视图，切换后创建的新任务采用新视图，已有任务和重试保持原视图。生成结果与记录标注正背。只提供正面素材时，背面是模型推测；要准确还原背部细节，应接入真实背面参考图。

本轮已完成目录导入与连线的浏览器检查、12 项平铺逻辑测试，没有追加背面或批量计费生成。

文件夹图片节点也支持把本地多张图片或整个目录直接拖到节点内追加，包含子目录；已有列表保留，同一路径/大小/修改时间的重复项跳过。拖入时显示高亮提示。正在读取时请等当前导入完成，再继续添加。导入后在平铺节点点击「更新上游」。

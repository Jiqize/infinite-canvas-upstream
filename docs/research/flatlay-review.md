# 平铺功能合并审查

## 需求价值

适合当前画布：将单品图生成封装为流程节点，保留普通图片产物；文件夹导入减少逐图连线，正背模式与透明底满足服装单品整理。建议保留并合入本地新画布主线。

## 实现质量

已修复两项问题：

- 文件夹节点导出的资源 URL 是会话 Blob 地址，原先重开画布后可能失效。宿主恢复画布时现在根据 storageKey 恢复文件夹资源 URL。
- 停止恰逢图片存储返回时，原先先检查取消再保存任务引用，会遗漏已成功保存的结果。现在先保存白底/透明底检查点再响应停止，重试复用已有产物。

验证：平铺/拖放 17 项测试与腾讯服务 7 项测试通过；浏览器将文件夹两张图片 URL 人为设为过期后恢复，两张均可读取，storageKey 保持不变。检查了递归本地存储引用收集与画布导出，均会包含节点内图片。没有新增计费请求；依项目规则不执行全量构建或类型检查。

此前已实测单图白底生成和腾讯 GoodsMatting，透明 PNG 有真实 alpha，COS 临时对象清理完成。背面质量、多图真实队列、自动识别、Finder 原生目录拖放仍属于待验收边界，不能以定向测试代替。

## 合并范围

本功能基于 feat/node-pack 的 cf2417c。本地 main 跟踪 basketikun 上游；上游最新 origin/main 为 9cd3dea，比本地 main 多两个文档提交。当前功能分支还带有此前 24 个主题/节点包等祖先提交，直接合并会一并纳入。

Jiqize/Infinite-Canvas 的 fork/main 为另一套 Python/Feebee 项目，与当前新画布无共同历史，不能向其直接推送。合并目标与最终范围待用户明确；未修改本地或远端 main。

已在功能分支整合 origin/main 的两个文档提交，仅 CHANGELOG 发生冲突，保留本分支 Unreleased 条目与上游 v0.20.0 版本分界；README 和品牌资源保留上游更新，无代码冲突。
